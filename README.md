# SpinWorks Surfaces bridge

The official, inspectable reference bridge for connecting a local agent session
to [SpinWorks Surfaces](https://surfaces.spinworks.ai).

The bridge is intentionally small: one readable Node.js executable, no runtime
dependencies, and a package check that fails if the published boundary grows
unexpectedly. It generates an Ed25519 key on the user's Mac, proves possession
to Surfaces, stores the private key and session credentials in macOS Keychain,
and signs every authenticated request. The private key is never sent to
Surfaces or printed.

## Status

The source repository is public and licensed under Apache-2.0. The package is
prepared for the `@spinworks-ai` npm scope, but version `0.1.0` is not available
from npm until the SpinWorks npm organization and first-publish trust ceremony
are complete. Until then, do not treat an npm package with this name as
official.

## Requirements

- macOS, because version `0.1.0` stores credentials in Apple Keychain
- Node.js 22.14.0 or newer
- a short-lived pairing code generated by a Surfaces workspace owner

## Connect

Once `@spinworks-ai/surfaces-bridge@0.1.0` is published and allowlisted by the
Surfaces server, use the exact version shown by Surfaces:

```bash
npm exec --yes \
  --package=@spinworks-ai/surfaces-bridge@0.1.0 \
  -- surfaces-bridge connect \
  --origin https://agents.surfaces.spinworks.ai \
  --code SURF-ABCD-2345
```

Then inspect the stored connection:

```bash
npm exec --yes \
  --package=@spinworks-ai/surfaces-bridge@0.1.0 \
  -- surfaces-bridge status
```

Run `surfaces-bridge` without a command to see all supported operations.

## Security boundary

The package never contains a Surfaces access token, model-provider credential,
signing private key, repository credential, or environment secret. Pairing
codes are short-lived and single-use. The Surfaces server also enforces an
exact bridge-version allowlist; a public package alone is not authority to
connect.

Please report vulnerabilities privately using the instructions in
[SECURITY.md](SECURITY.md).
